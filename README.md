In the repository, we walk through the steps to scrape the [College football data](collegefootballdata.comg). Due to terms and services, I cannot post the full data set to this repository. Instead you can request your *free* API key at the website above. To reproduce my work, you can add your API key to your `.env` file labeled as `API_KEY = {your_API_key}`. Then you can run the `acquire_data.qmd` file. In this file, we pull data from 2 different endpoints (recruiting and results), clean the data sets, merge the two, and then save it off to a csv file. The data we keep is from 2018 to 2024, with each teams `recruiting_score`, `recruiting_rank`, `conference`, and `win_pct`. The data also includes the name of the team and the year for which this occurred. 

In `eda.qmd`, we make basic plots that look at win percentage vs recruiting rank. We start with a plot colored by year but since that is kind of overwhelming to look at, we move to plotting the scatterplots separate for each year. After this we look at the overall correlation between the the recruiting rank and win percentage. Then we look at each individual year's correlation to see if there are differences between year. Next, we look at the correlation based on conferences. Then, we group the data into the teams that were in the top 10 at least one of those years and sort descending by the win percentage. Finally, we look at the teams with the bottom 10 recruiting rank from each year. Again sorting descending by win percentage to see if low ranked recruiting classes can still have high win percentages.

*Note:* If you clone this repo and get your own API key and paste it in your `.env`, everything should be set in the `.gitignore` to not post the data and the API key to GitHub. To not violate the terms and service please check that this has worked correctly and we are not posting API keys to GitHub or posting the data.
